TextToSpeech と NTT の音声合成 API（結月ゆかりボイス）、Live2D の SDK、Unity を組み合わせて、喋り相手を作った。

詰まったのは音声データの並び順だった。NTT の API から返ってくる音声はビッグエンディアンで、そのまま再生しようとしても音にならない。バイトを入れ替えてリトルエンディアンの wav を組み直したら、ようやく声が出た。

Stack Overflow で変換方法を書いてくれたどこかの国の人には、いまでも感謝している。

長いこと、ごく一部の知人にしか見せていなかった。隠すほどのものでもないと思うようになったので、ここに置いておく。
